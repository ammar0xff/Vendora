# Anti-AI Defaults: Replacement Map

| AI-default tell | Professional replacement |
|---|---|
| Indigo→violet gradient as identity | Use existing brand roles and product semantics; if none exist, establish a restrained role-based palette based on context |
| Inter on pure white, no type variation | Use the project's licensed/approved typeface and a clear hierarchy for page title, section label, body, metadata, and numeric data |
| One radius everywhere | Assign radii by component role: compact control, standard control, panel, pill, overlay |
| One soft shadow everywhere | Use borders/surface contrast by default; elevation only for menus, dialogs, and truly floating layers |
| “Build the future of work” headline | State the actual task, status, or decision: e.g. “Accounts requiring attention” |
| Three emoji feature cards | Use real workflow steps, data, or capabilities with consistent Lucide icons only where they aid scanning |
| Four equal KPI cards | Rank information by the decision it supports; give the primary signal more prominence and remove redundant metrics |
| Every button is primary | One dominant action per state; secondary, tertiary, and destructive actions have distinct treatments |
| Lorem ipsum / John Doe / Get Started | Use verified product copy and domain-specific sample data clearly labeled as sample |
| Invented growth percentages | Omit or mark unavailable; only display metrics with a source, definition, and time range |
| No loading/empty/error/permission state | Design state-specific content and a useful recovery action for each |
| Mobile is desktop stacked | Re-evaluate content priority, interaction mode, filters, and row structure at 390 px |
| Motion on every element | Animate only meaningful state changes and spatial transitions; honor reduced motion |
| Decorative charts and summary panels | Keep only information that supports the page outcome |
| Raw divs for everything | Use semantic HTML and accessible shadcn/ui primitives; create typed components |
| Essential data truncated | Reflow, disclose, wrap, or offer a detail path; never hide decision-critical values |
| Color-only status | Pair color with text, icon, shape, or accessible label |

## Five-step repair order

1. **Page contract:** define user, outcome, information, actions, real content, failure modes, and states.
2. **Structure and hierarchy:** delete redundant regions; prioritize information by decision value.
3. **Foundations and components:** map semantic roles to tokens and reuse the catalog.
4. **States and responsive behavior:** cover all states and deliberate 1440/768/390 behavior.
5. **Decoration and polish:** refine contrast, borders, density, icons, and only then purposeful motion.
